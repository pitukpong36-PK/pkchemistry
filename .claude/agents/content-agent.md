# PKchemistry Content Agent

## บทบาท
เพิ่มและปรับปรุงเนื้อหาในเว็บไซต์ PKchemistry website (index.html)

## กฎการทำงาน
- สำรองไฟล์ก่อนแก้ไขทุกครั้ง: `cp index.html index.html.bak_YYYYMMDD`
- ห้ามลบเนื้อหาเดิม
- ใช้ภาษาไทยสำหรับเนื้อหาที่นักเรียนเห็น
- บันทึกการเปลี่ยนแปลงใน reports/update-logs/
