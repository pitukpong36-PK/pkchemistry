# รายงานตรวจสอบลิขสิทธิ์ก่อนอัปขึ้นเว็บ (2026-06-20)

เป้าหมาย: ทำให้ `index.html` อัปขึ้นโฮสต์สาธารณะได้โดยไม่ติดปัญหาลิขสิทธิ์
หลักการ: **ปัญหาลิขสิทธิ์เกิดจากการ "ฝัง/โฮสต์" เนื้อหาของผู้อื่น** ไม่ใช่การ "ลิงก์ออก"
(การลิงก์ไปเว็บอื่น เช่น YouTube/Khan Academy เป็นเรื่องถูกกฎหมาย ไม่ละเมิดลิขสิทธิ์)

## ✅ สิ่งที่แก้ไขแล้ว (ความเสี่ยงจริง — เนื้อหาฝังจากเซิร์ฟเวอร์ภายนอก)

**รูปภาพ hotlink จาก Wikimedia Commons 22 รูป → แทนด้วย inline SVG ที่วาดเองทั้งหมด**
- 9 สัญลักษณ์ GHS (บท c1b1) → กรอบสี่เหลี่ยมข้าวหลามตัดแดง + สัญลักษณ์ (สัญลักษณ์ GHS เป็นมาตรฐาน UNECE = สาธารณสมบัติ)
- 6 รูปทรงโมเลกุล VSEPR (บท c1b3) → ball-and-stick วาดเอง (atom + bond ตามมุมจริง)
- 7 รหัสรีไซเคิลพลาสติก (บท c5b13) → สามเหลี่ยมลูกศรเขียว + เลข 1–7
- อัปเดต caption credit 3 จุด (ไม่อ้าง Wikimedia แล้ว ระบุว่าวาดเองในเว็บ)
- ลบการ์ด "Wikimedia Commons" ในส่วนแหล่งอ้างอิง (เพราะไม่ได้ใช้รูปจากที่นั่นแล้ว)
- ผล: **ไม่เหลือเนื้อหาฝังจากภายนอกเลย** (img/iframe/video/audio/embed ที่ชี้ http = 0)

## หมายเหตุ / ข้อเสนอแนะ (ไม่บังคับ)
1. **เนื้อหาตัวอักษร**: คำอธิบายภาษาไทยเป็นงานเขียนของผู้จัดทำเอง ความเสี่ยงต่ำ — แต่ควรเลี่ยงคัดลอกข้อความ/รูปจากตำราตรง ๆ (ลิงก์อ้างอิงที่มีอยู่ใช้เพื่ออ้างอิง ไม่ได้คัดเนื้อหามา)
2. **Google Fonts** เป็น "ทรัพยากรภายนอก" ชิ้นเดียวที่เหลือที่โหลดจริง (ถูกลิขสิทธิ์) — ถ้าต้องการให้เว็บทำงานออฟไลน์/ไม่พึ่ง CDN เลย สามารถดาวน์โหลดไฟล์ฟอนต์มาโฮสต์เองพร้อม @font-face ได้ (ฟอนต์ยังเป็น OFL เหมือนเดิม) — เป็นการปรับเสริม ไม่เกี่ยวกับลิขสิทธิ์
3. **media.json / คลังสื่อ**: เก็บเฉพาะ URL + ชื่อคลิป (ลิงก์ออกไป YouTube) ไม่ได้ฝังวิดีโอ — ปลอดภัย
