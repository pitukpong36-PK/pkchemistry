# คลังโจทย์จาก Google Sheets — คู่มือตั้งค่า

ให้เว็บดึงโจทย์จาก Google Sheets ได้ → แก้โจทย์ในชีตเหมือนพิมพ์ Excel โดยไม่ต้องแตะโค้ด
(เปิดผ่านเว็บจริง/https เท่านั้น; เปิดแบบดับเบิลคลิก file:// จะใช้โจทย์ที่ฝังในหน้าเหมือนเดิม)

## โครงสร้างชีต (แท็บเดียว, 8 คอลัมน์)

| บท | คำถาม | ตัวเลือก ก | ข | ค | ง | เฉลย(1-4) | คำอธิบาย |
|----|-------|-----------|---|---|---|-----------|----------|
| c1b1 | 2.5 × 3.42 = ? | 8.55 | 8.6 | 9 | 8.550 | 2 | 2.5 มี 2 เลขนัยสำคัญ → 8.6 |
| c1b2 | อนุภาคใดมีประจุลบ? | โปรตอน | นิวตรอน | อิเล็กตรอน | นิวเคลียส | 3 | อิเล็กตรอนประจุลบ |

กติกา:
- **แถวแรกเป็นหัวตาราง** (ระบบข้ามให้อัตโนมัติถ้าคอลัมน์ "เฉลย" ไม่ใช่ตัวเลข 1-4)
- **บท** = รหัสบท เช่น `c1b1`, `c1b2`, `c2b4` … `c6b14` (ดูรหัสได้จากชื่อบทในเว็บ)
- **เฉลย** = เลข **1-4** (ก=1, ข=2, ค=3, ง=4)
- ต้องมีตัวเลือกครบ **4 ช่อง** — แถวที่กรอกไม่ครบหรือเฉลยไม่ใช่ 1-4 จะถูกข้าม
- คำอธิบายเว้นว่างได้
- ใส่ comma หรือขึ้นบรรทัดในข้อความได้ (Google จะใส่เครื่องหมายคำพูดให้เองตอน export)

## สำคัญ: บทที่อยู่ในชีต จะ "แทนทั้งบท"
ถ้าใส่บท `c1b1` ในชีต โจทย์ `c1b1` ทั้งหมดจะมาจากชีต (โจทย์ฝังในหน้าของบทนั้นถูกแทน)
→ **ก่อนเริ่มจัดการบทใดในชีต ให้วางโจทย์เดิมของบทนั้นให้ครบก่อน** แล้วค่อยเพิ่ม/แก้
(ใช้ไฟล์ `data/quiz-export.csv` ที่ผม export ให้ — มีโจทย์เขียนมือเดิมครบทุกบทพร้อมก๊อปวาง)
บทที่ไม่ใส่ในชีต = ใช้โจทย์ฝังในหน้าเหมือนเดิม → จึง "เริ่มจากน้อย ค่อย ๆ ย้ายทีละบท" ได้

## ⚠️ สำคัญที่สุด: กันชีตแปลงข้อมูลเพี้ยน

Google Sheets จะ "เดา" ชนิดข้อมูลให้อัตโนมัติ ซึ่ง **ทำให้เฉลย/ตัวเลือกเพี้ยน** ถ้าไม่ปิด เช่น
- จัดเรียงอิเล็กตรอน `2, 8, 1` → กลายเป็นวันที่ `2, 8, 2001` ❌
- ตัวเลือกขึ้นต้น `=` → กลายเป็นสูตร `#ERROR!` ❌
- `8.550` → `8.55`, `2.0` → `2`, `5.6%` → `5.60%` (ตัด/เพิ่มศูนย์)

**วิธีกัน — ตอน import CSV:**
File → Import → Upload `quiz-export.csv` → ในกล่อง import ให้ **เอาเครื่องหมายถูกออกจาก
"Convert text to numbers, dates, and formulas"** แล้วค่อย Import

**ถ้าวางมือ (paste) แทน:** เลือกทั้งชีต (Ctrl+A) → Format → Number → **Plain text** ก่อน แล้วค่อยวาง

## ขั้นตอนเปิดใช้งาน

1. สร้าง Google Sheets ใหม่ → **File → Import → Upload `data/quiz-export.csv`** →
   ปิด "Convert text to numbers, dates, and formulas" (ดูหัวข้อด้านบน) → Import
2. **File → Share → Publish to web**
3. เลือก: แท็บที่ใส่โจทย์ · รูปแบบ **Comma-separated values (.csv)** → กด **Publish**
4. คัดลอกลิงก์ที่ได้ (รูปแบบ `https://docs.google.com/spreadsheets/d/e/XXXX/pub?gid=0&single=true&output=csv`)
5. ส่งลิงก์ให้ผม หรือวางเองในไฟล์ `index.html` ที่ตัวแปร:
   ```js
   const QUIZ_SHEET_URL = '';   // ← วางลิงก์ CSV ตรงนี้
   ```
6. เปิดเว็บผ่าน https → เปิด Console (F12) ดูข้อความ `[quiz] โหลดโจทย์จากชีต N ข้อ`

## แก้โจทย์หลังเปิดใช้แล้ว
แก้ในชีตได้เลย — Google อัปเดตไฟล์ที่ publish ภายในไม่กี่นาที เว็บดึงใหม่ทุกครั้งที่โหลดหน้า (ตั้ง `cache:'no-cache'`)
ระดับความยาก (ง่าย/กลาง/ยาก) ระบบคำนวณเองจากข้อความ ไม่ต้องกรอก
