# 🔗 v.3 ด้านที่ 3 (ยกระดับแล็บ/เกม) — เชื่อม แล็บ→ควิซ→ทบทวน — 2026-06-25

## เป้าหมาย
ปิดวงจรการเรียนรู้ให้ครบ: **เรียนบท → ทดลองในแล็บ → ทำแบบทดสอบ → ข้อที่ผิดเข้าระบบทบทวน (SRS)**
- เดิมมีลิงก์ทางเดียว: เนื้อหาบท → "ลองแล็บ" (ปุ่มในแต่ละบท)
- ยังขาด: จากแล็บกลับไปทดสอบความเข้าใจ → ป้อนเข้าระบบทบทวนที่เพิ่งสร้าง (commit 860d5c5)

## สิ่งที่เพิ่ม (กระทบน้อย — จุดเดียวครอบทุกแล็บ)
1. **แมพ `LAB_CHAP`** แล็บ id → บท id ทั้ง 14 คู่ (safety→c1b1 ... enviro→c6b14)
2. **`Lab.open`** เก็บ `Lab._curId = id` (แล็บที่กำลังเปิด)
3. **`Lab._labHead`** เติมปุ่ม "📝 ทดสอบความเข้าใจ" ในหัวแล็บ → `PK.startQuiz(cid)`
   - แสดงเฉพาะบทที่มีควิซ (guard `PK.hasQuiz(cid)`) → บทไม่มีควิซจะไม่ขึ้นปุ่ม (graceful)
4. CSS `.lab-quiz-cta` (ปุ่มไล่ขวาในหัวแล็บ + responsive)
5. bump `sw.js` v8 → **v9**
