## 3. สถาปัตยกรรม — Dual Mode (จุดสำคัญ)

เว็บเป็นไฟล์ HTML เดี่ยว เปิดด้วยดับเบิลคลิก (ไม่มีเซิร์ฟเวอร์) จึงออกแบบ 2 โหมด:

| โหมด | เงื่อนไข | ที่เก็บข้อมูล | นับข้ามเครื่อง |
|------|----------|--------------|----------------|
| **เดโม (ค่าเริ่มต้น)** | ยังไม่ใส่คีย์ Firebase | localStorage | ไม่ (เครื่องนี้) |
| **คลาวด์** | ใส่ `firebaseConfig` จริง | Firebase Auth + Firestore | ใช่ (ทั่วโลก realtime) |

- ตรวจ `CLOUD = !/^YOUR_/.test(apiKey)` → เลือก backend อัตโนมัติ
- Cloud ใช้ **dynamic `import()`** โหลด Firebase SDK เฉพาะเมื่อจำเป็น → โหมดเดโมทำงานออฟไลน์ได้
- ถ้า Firebase init ล้มเหลว → fallback กลับโหมดเดโมอัตโนมัติ
- ทั้งสอง backend ใช้ interface เดียวกัน (register/login/logout/trackChapter/trackProblem) + callback `PK._onAuth/_onCounters/_onProgress`
