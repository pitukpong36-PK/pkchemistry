# 2026-06-23 · เฟส 4 (สมจริง) — เครื่องยนต์อนุภาคแก๊ส (POC)

## เป้าหมาย
แล็บเดิมเป็นภาพกึ่งนิ่ง (เปลี่ยนค่า → วาด SVG ใหม่). แก๊สใช้ CSS `gasJit` ให้อนุภาค
สั่นอยู่กับที่ ไม่ได้วิ่งชนผนังจริง (n×7 อนุภาค). ยกระดับเป็นซิมูเลชันจริง เริ่มที่แล็บแก๊ส
เป็น proof-of-concept ของแนวทาง "เครื่องยนต์อนุภาค rAF" ที่จะนำไปใช้ซ้ำกับแล็บอื่น

## สิ่งที่ทำ (index.html, classic script — แล็บแก๊ส c3b7)
- แทน `Lab._gasSvg()` (SVG นิ่ง) ด้วย `<canvas id="gasCanvas">` + เครื่องยนต์อนุภาค:
  - `Lab._gasEng {raf,parts}` — เก็บสถานะอนุภาค (คงอยู่ข้าม re-render → ลื่นไม่กระตุก)
  - `Lab._gasStart()` — รัน `requestAnimationFrame` loop: อนุภาควิ่ง ชนผนังสะท้อนมุม
  - `Lab._gasBounds()` — กรอบ/ตำแหน่งลูกสูบจาก V (vFrac)
  - `Lab._rRect()` — helper วาดสี่เหลี่ยมมุมโค้งบน canvas
  - `Lab._stopAnim()` — `cancelAnimationFrame` กันรั่ว
- ฟิสิกส์: ความเร็ว ∝ √(T/300) (ทฤษฎีจลน์) · จำนวนอนุภาค = clamp(round(n×12), 4..40)
  · ลูกสูบขยับตาม V · แต่ละอนุภาคมี sp สุ่ม → ดูเป็นการกระจายความเร็ว
- ระบบหยุด (กัน rAF leak) 3 ชั้น:
  1. `Lab.open()` เรียก `_stopAnim()` ก่อนเปิดแล็บอื่น
  2. `Lab.openHub()` เรียก `_stopAnim()` เมื่อกดกลับ
  3. ใน loop เช็ค `getElementById('gasCanvas')` — ถ้า canvas หาย (เปลี่ยนหน้า) หยุดเอง

## ทดสอบ (jsc + stub DOM/rAF — เครื่องนี้ไม่มี node/deno)
- syntax: ช่วงโค้ดแก๊ส parse ผ่าน (new Function) · วงเล็บ balance 158/158, 30/30, 6/6
- พฤติกรรม (รัน 300 เฟรมจำลอง):
  - [1] n=1 → 12 อนุภาค, อยู่ในกรอบครบหลัง 300 เฟรม ✓
  - [2] จำนวน ∝ n: n=3→36, n=0.2→4 (clamp) ✓
  - [3] ความเร็ว ∝ √T: ก้าวเฉลี่ย T300=0.613 / T600=0.854 = 1.393 ≈ √2 ✓
  - [4] _stopAnim → raf=0 ✓
  - [5] canvas หาย → loop หยุดเอง ไม่ schedule ต่อ ✓
- HTTP 200 · ไม่เหลือ reference `_gasSvg`

## ยังไม่ได้ยืนยัน
- การวาดบน canvas จริง (พิกเซล) — stub ctx ไว้ตอนทดสอบ. ควรเปิดเบราว์เซอร์จริงดู
  อนุภาควิ่ง/ลูกสูบ/สีพื้นครั้งหนึ่ง (โค้ดวาดเป็น canvas API มาตรฐาน)
- CSS keyframe `gasJit` กลายเป็น dead (ไม่มีผู้ใช้แล้ว) — ปล่อยไว้ ไม่กระทบ
