# 2026-06-18 — ฟีเจอร์ใหม่: สารบัญหัวข้อในบท (Chapter Table of Contents)

## สรุป
เพิ่มฟีเจอร์ **"สารบัญหัวข้อในบท"** — ปุ่มลอย (FAB) สีเหลืองอำพันที่หน้าบทเรียน
เปิดแผงสารบัญที่สร้างอัตโนมัติจากหัวข้อ `<h3>` ในเนื้อหาบท นักเรียนแตะเพื่อกระโดดไปยัง
หัวข้อที่ต้องการได้ พร้อม scroll-spy ไฮไลต์หัวข้อปัจจุบันตามตำแหน่งสกรอลล์

## ทำไมเลือกฟีเจอร์นี้
- **ยังไม่มีในเว็บ** — ตรวจแล้วว่ามีอยู่: back-to-top (ปุ่มลอย ↑), reading progress bar,
  drawer มือถือ, dark/light, flashcards, mock exam, ระบบความยาก, backup/restore,
  ปรับฟอนต์/accessibility, มินิเกม, PWA, Firebase — แต่ยัง**ไม่มี TOC/สารบัญในบท**
- **มีประโยชน์จริงกับ ม.ปลาย บนมือถือ** — แต่ละบทเป็นหน้าเดียวที่ยาวมาก (เนื้อหา richHTML
  หลายสิบ section) การเลื่อนหามือถือลำบาก สารบัญกระโดดได้ช่วยให้หาเนื้อหาได้ไว
- **ความเสี่ยงต่ำ** — CSS + JS เล็กน้อย, self-contained บน `window.PK_TOC`,
  ไม่แก้ลอจิกเดิม, ไม่แตะ Firebase/PWA/เกม/เนื้อหา, มี guard ทุกจุด
- เสริมกับของเดิมพอดี (อ่านถึงไหน = reading bar, กลับบนสุด = back-top, กระโดดหัวข้อ = TOC ใหม่)

## ทำงานอย่างไร
1. เมื่อเปิดบท `showChapter()` เรียก `window.PK_TOC.build()`
2. `build()` สแกน `<h3>` ใน `#chap-body` → ใส่ `id` (`toc-h-N`) + `scroll-margin-top:80px`
   (กันแถบนำทางบังหัวข้อ) แล้วสร้างรายการปุ่มในแผง
3. แตะปุ่ม FAB (☰) → เปิดแผง slide-up + backdrop; แตะรายการ → smooth scroll ไปหัวข้อนั้น
4. scroll-spy: รวมเข้ากับ `uxScroll()` เดิม — ไฮไลต์หัวข้อที่กำลังอ่าน, ซ่อน FAB
   เมื่อออกจากหน้าบทเรียนหรือบทไม่มีหัวข้อย่อย
5. ปิดด้วยปุ่ม ×, แตะ backdrop, หรือกด Escape

## แก้ไขตรงไหน (index.html)
- **CSS** (~บรรทัด 809): เพิ่มสไตล์ `.toc-fab`, `.toc-backdrop`, `.toc-panel`, `.toc-list`,
  `.toc-empty` + override dark mode + `@media print` ซ่อน
- **DOM** (หลังปุ่ม back-top ~บรรทัด 1453): เพิ่ม `#tocFab`, `#tocBackdrop`,
  `#tocPanel` (มี `#tocList`)
- **Block A classic** (`showChapter`, ~บรรทัด 15201): เพิ่ม hook `if (window.PK_TOC) window.PK_TOC.build();`
- **Block C module** (หลัง `uxScroll`, ~บรรทัด 16838): เพิ่ม object `window.PK_TOC`
  + รวม `PK_TOC.onScroll()` เข้ากับ `uxScroll()` + Escape handler

## เรื่อง script scope
- `showChapter` อยู่ Block A (classic), `PK_TOC` อยู่ Block C (module) → ไม่ข้าม scope กัน
  จึงผูกทุกอย่างบน `window.PK_TOC` และเรียกผ่าน `window.*` เท่านั้น (มี guard `if(window.PK_TOC)`)

## วิธีทดสอบในเบราว์เซอร์
1. เปิด index.html → เมนู "เนื้อหาวิชา" → เลือกวิชา → เปิดบทเรียนใดก็ได้
2. เห็นปุ่มกลม ☰ สีเหลืองอำพันมุมขวาล่าง (เหนือปุ่ม ↑) → แตะเปิดสารบัญ
3. แตะหัวข้อ → หน้าเลื่อนไปหัวข้อนั้น; เลื่อนอ่านเอง → หัวข้อปัจจุบันถูกไฮไลต์
4. กด × / แตะพื้นหลังมัว / Escape → ปิดแผง
5. กลับหน้าอื่น (หน้าแรก/เครื่องมือ) → ปุ่ม ☰ หายไป (โผล่เฉพาะหน้าบทเรียน)
6. สลับ dark mode → สีแผงและไฮไลต์ปรับตามธีม
7. console ควรไม่มี error ใหม่
