# 2026-06-23 · เฟส 4 (สมจริง) — เคมีไฟฟ้า canvas (อิเล็กตรอน/ไอออนเคลื่อน)

ต่อจากแก๊ส/อัตรา/สมดุล/ไทเทรต — ยกระดับแล็บเคมีไฟฟ้า (c4b11) เป็น canvas/rAF

## เดิม
SVG: อิเล็กตรอน 3 ลูกวิ่งบนลวด (`<animate>`) แต่สารละลายในบีกเกอร์นิ่งสนิท

## ใหม่ (Lab._echStart ใช้ runner กลาง)
- อิเล็กตรอน 6 ตัวไหลตามเส้นลวด (polyline แอโนด→แคโทด) ด้วย helper `Lab._along(pts,t)`
  — ความเร็ว ∝ E°cell (spd 0.004→0.011 ที่ 0.5→2.5 V)
- ไอออน 12 ตัวเคลื่อนในบีกเกอร์ทั้งสอง (สีน้ำเงิน/น้ำตาลตามฝั่ง) ชนผนังด้วย `Lab._bounce`
- คงโครงฉากเดิม: โวลต์มิเตอร์ + ค่า E°cell, ลวด, สะพานเกลือ, บีกเกอร์, ขั้ว, ป้ายแอโนด/แคโทด
- กรณีเลือกโลหะเหมือนกัน → return ก่อน (ไม่มี canvas) loop หยุดเองด้วย DOM guard

## ทดสอบ (jsc + stub, 120 เฟรม)
- ไม่เหลือ `_echSvg` · canvas id ครบ
- [ALONG] t0=[70,60] t1=[250,60] (ปลายเส้นถูก)
- [ECH] electrons=6 เคลื่อนจริง · ions=12 อยู่ในบีกเกอร์ ✓
- [ECH] speed ∝ Ecell: step@0.5V=0.0054 < step@2.5V=0.0110 ✓
- [GUARD] canvas หาย → ไม่ schedule ต่อ ✓ · HTTP 200

## ยังไม่ยืนยัน
- พิกเซลจริง (stub ctx) — ควรเปิดเบราว์เซอร์ดูครั้งหนึ่ง
- helper `Lab._along` ใหม่ ใช้ซ้ำได้กับแล็บอื่นที่มีการไหลตามเส้น

## เหลือทำ (แล็บที่ยังเป็นภาพนิ่ง/ได้ประโยชน์)

- อะตอม (มี SVG โบร์หมุนอยู่แล้ว — optional)
