## แล็บที่เพิ่ม
### 💧 เจือจางสารละลาย (c2b5) — id `dilute`
- เลื่อนปรับ M₁ (0.1–5 M), V₁ (10–100 mL), น้ำที่เติม (0–200 mL)
- บีกเกอร์ SVG ก่อน/หลัง — ระดับของเหลว ∝ ปริมาตร, ความเข้มสี ∝ ความเข้มข้น
- แสดง M₁V₁=M₂V₂ แทนค่าจริง + V₂, M₂, อัตราเจือจาง, โมลคงที่

### 💨 กฎของแก๊ส PV=nRT (c3b7) — id `gas`
- 4 โหมด: Boyle (T,n คงที่→ปรับ V), Charles (P,n→ปรับ T), Gay-Lussac (V,n→ปรับ T), Avogadro (P,T→ปรับ n)
- กระบอกสูบ-ลูกสูบ SVG: ความสูงแก๊ส ∝ V, จำนวนอนุภาค ∝ n, ความเร็วสั่น (CSS gasJit) ∝ T
- คำนวณตัวแปรตามด้วย PV=nRT (R=0.0821) + แสดงค่า P/V/T/n + ตรวจ PV=nRT

### 🧫 ไทเทรตกรด-เบส (c4b10) — id `titrate`
- HCl 0.1 M 25 mL + NaOH 0.1 M · เลื่อนหยดเบส 0–50 mL
- กราฟ pH–ปริมาตร SVG (polyline) + เส้นจุดสมมูล + จุดปัจจุบัน
- pH คำนวณจากโมล H⁺/OH⁻ เหลือ/เกิน · บีกเกอร์เปลี่ยนสีตามฟีนอล์ฟทาลีน (ไม่มีสี→ชมพู ที่ pH≥8.2)
