# บันทึกการเพิ่มฟีเจอร์เกม RPG (รอบ 2) — 2026-06-17

ไฟล์: index.html | สำรอง: index.html.bak_20260617_rpg_features

## ฟีเจอร์ที่เพิ่ม
1. **คริติคอล (Critical Hit)** — ตอบถูกมีโอกาสคริติคอล (8% + คอมโบ×5%, สูงสุด 45%) ดาเมจ ×1.8 + ข้อความ "✨ คริติคอล!"
2. **ตัวเลขดาเมจเด้ง (combat juice)** — เลขดาเมจลอยขึ้นบนมอนสเตอร์เมื่อโจมตี (คริติคอลตัวใหญ่สีทอง) ผ่าน CSS keyframe rpgPop
3. **ไอเทมดรอปจากมอนสเตอร์** — ปราบมอนสเตอร์มีโอกาสดรอป ยา/คำใบ้/ทอง (บอสดรอปแน่นอน)
4. **โหมดท้าทาย (เอนด์เลส)** — สู้คลื่นมอนสเตอร์ไม่รู้จบ โจทย์คละทุกบท สเกลตามคลื่น บอสทุกคลื่นที่ 5 เก็บสถิติคลื่นดีสุด
5. **ระบบสถิติ + ความสำเร็จ (Achievements)** — หน้า 📊 สถิติ: ปราบมอนสเตอร์/บอส, คอมโบสูงสุด, ความแม่นยำ, คริติคอล, ดรอป, เคลียร์บท, เอนด์เลสดีสุด + 8 ความสำเร็จปลดล็อกตามเงื่อนไข

## จุดที่แก้ใน index.html
- state: `_default/load/save` เพิ่ม `stats{}` และ `best{endless}` (backward-compatible)
- `answer`: คริติคอล + บันทึก stats (answered/correct/crits/maxCombo) + ตั้ง RB.fx
- `renderBattle`: แบนเนอร์โหมดเอนด์เลส + ป็อปดาเมจจาก RB.fx
- `nextBattle`: รองรับเอนด์เลส (สุ่มบท สเกลตามคลื่น) + ตั้ง RB.dmg ต่อการต่อสู้
- `defeatMob`: รวมลอจิก + ไอเทมดรอป + เอนด์เลส + นับ kills/bosses
- `gameOver`: รู้โหมดเอนด์เลส แสดงคลื่นที่ไปถึง
- เพิ่ม `rollDrop / startEndless / showStats` + `RPG_ACH[]`
- showMap: เพิ่มการ์ดโหมดเอนด์เลส + ปุ่ม 📊 สถิติ
- CSS: re-pop/rpgPop, rpg-endless, stat-grid, ach-list

## ตรวจสอบ (jsc + Chrome headless)
- jsc: คริติคอล/stats นับถูก, ดรอปสะสม (potion 2→4, hint 1→4), เอนด์เลสสเกล+บอสทุกคลื่น 5, เอนด์เลสตายบันทึก best, สถิติปลดล็อก 7/8 achievement, persistence round-trip stats/best ครบ
- syntax: <script> หลัก parse ผ่าน
- ภาพจริง (Chrome): หน้าสถิติ+ความสำเร็จ และหน้าต่อสู้โหมดเอนด์เลส แสดงถูกต้อง
