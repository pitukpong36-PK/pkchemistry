# 📈 v.3 ด้านที่ 2 (แดชบอร์ดการเรียนรู้) — Spaced Repetition + สรุปความแม่นยำ — 2026-06-25

## เป้าหมาย
หน้าโปรไฟล์มีแดชบอร์ดอยู่บ้างแล้ว (ความก้าวหน้ารายบท · คะแนนควิซ best/% · points/streak/badges)
แต่**ยังขาด**: ระบบทบทวนข้อที่เคยผิด (ไม่เคยเก็บว่าข้อไหนผิด) + ภาพรวมความแม่นยำ/บทที่ควรเน้น

## สิ่งที่เพิ่ม
### 1) โมดูล SRS (Spaced Repetition — Leitner box) — เก็บใน localStorage
- คีย์ `pk_srs_{email|guest}` (per-user, ทำงานออฟไลน์ + ตอน logout ก็ได้)
- โครงสร้างต่อข้อ: `{ch, q, box(1–5), due, right, wrong}` คีย์ = `chapterId|hash(คำถาม)`
- ช่วงทบทวน (box→เวลา): box1 = ทันที · box2 = 1 วัน · box3 = 3 วัน · box4 = 7 วัน · box5 = จำได้แล้ว (ลบออก)
- กติกา: ตอบผิด → เข้า box1 (ทบทวนทันที) · ตอบถูกในคิว → เลื่อน box สูงขึ้น (ทิ้งช่วงนานขึ้น) ·
  ตอบถูกตั้งแต่แรก (ไม่เคยผิด) → ไม่เพิ่ม · ผิดซ้ำ → รีเซ็ต box1

### 2) จุดเก็บข้อมูล (hook)
- `PK.answer` เพิ่ม 1 บรรทัด: `SRS.record(ch, คำถาม, ถูก/ผิด)` (ทั้งควิซรายบทและโหมดทบทวน · ข้าม exam)

### 3) โหมดทบทวน `PK.startReview()`
- ดึงข้อที่ `due ≤ now` มาประกอบใหม่จาก `QUIZ_BANK` (จับคู่ด้วยข้อความคำถาม) แล้วใช้ **UI ควิซเดิม**
- `QZ.ch='__review'`, `QZ.review=true` · จัดการใน `showResult` (ไม่บันทึกเป็นคะแนนบท, แสดง "เหลือทบทวนอีก N ข้อ")
  และ `exitQuiz` (กลับหน้าโปรไฟล์)

### 4) การ์ดแดชบอร์ดในหน้าโปรไฟล์ (`renderSRS`)
- สถิติ 3 ช่อง: ถึงกำหนดทบทวน · ข้อที่ติดตาม · ความแม่นยำควิซเฉลี่ย (จาก best/total ทุกบท)
- แถบ "📉 ควรเน้น": บทที่คะแนนควิซ < 60% (สูงสุด 3 บท)
- ปุ่ม "เริ่มทบทวน N ข้อ" (disabled เมื่อไม่มีข้อถึงกำหนด) + คำอธิบายระบบ
