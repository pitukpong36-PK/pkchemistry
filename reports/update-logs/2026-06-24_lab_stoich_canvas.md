# 2026-06-24 · เฟส 4 (สมจริง) — ปริมาณสัมพันธ์ canvas (สารกำหนดปริมาณ)

ยกระดับแล็บปริมาณสัมพันธ์ (c2b6) — เพิ่ม canvas คู่กับบาร์ชาร์ตเดิม

## ใหม่ (Lab._stoStart)
- canvas ภาพโมเลกุล "หลังทำปฏิกิริยา": ผลิตภัณฑ์ (∝ p.c·ξ) + สารเหลือ (∝ excess)
  โดย **สารกำหนดปริมาณหมดเกลี้ยง = ไม่มีอนุภาคในภาพ** → เห็น concept ตรง ๆ
- คงบาร์ชาร์ตเชิงปริมาณ (ก่อน/หลัง) + แผงคำนวณ ξ/ผลิตภัณฑ์/สารเหลือ ไว้ครบ
- re-seed เมื่อองค์ประกอบเปลี่ยน (เลือกปฏิกิริยา/ปรับโมล)

## ทดสอบ (jsc + stub, 120 เฟรม)
- amt[1,6] (H₂ เกิน): 20 อนุภาค = 8 ผลิตภัณฑ์ + 12 H₂เหลือ · N₂(จำกัด) ไม่มีในภาพ ✓ · ในกรอบ ✓
- amt[1,3] พอดีเป๊ะ: 8 อนุภาค (ผลิตภัณฑ์ล้วน ไม่มีเหลือ) ✓
- amt[0,0]: 0 อนุภาค → ขึ้น "ยังไม่เกิดปฏิกิริยา" ✓
- guard ✓ · HTTP 200
