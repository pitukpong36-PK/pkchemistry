# 🎮 v.3 ด้านที่ 3 (ยกระดับมินิเกม) — เกมป้อนข้อที่ตอบผิดเข้าระบบทบทวน (SRS) — 2026-06-25

## เป้าหมาย
ต่อยอดวงจรการเรียนรู้ v.3: ให้ "การตอบผิดในเกม" ป้อนเข้าระบบทบทวน (SRS) เหมือนที่ทำกับควิซ/แล็บ
→ ตอบผิดที่ไหนก็ได้ (ควิซ · ควิซจากแล็บ · เกม) ไหลเข้าการ์ดทบทวนในโปรไฟล์ที่เดียว

## ขอบเขตรอบนี้ (2 เกมหลักที่ใช้โจทย์คลังจริง + ตาคนล้วน)
- **เคมีมาร์เบิล** (`showGameQuestion` / `Game.answer`)
- **บันไดงูเคมี** (`snkShowQ` / `Snake.answer`)

ทั้งสองเรียก UI ตอบเฉพาะ "ตาผู้เล่นคน" (บอทไม่เปิดหน้าตอบ → ไม่เรียก answer handler)
จึงบันทึกเฉพาะคำตอบของคนจริง ไม่ปนคำตอบบอท — ไม่ต้องเพิ่ม guard บอท

## สิ่งที่แก้ (4 จุดเล็ก ๆ)
- `showGameQuestion`: เก็บ `G.qCh = chId`, `G.qText = q.q`
- `Game.answer`: `try{ if(G.qCh) SRS.record(G.qCh, G.qText, correct); }catch(e){}`
- `snkShowQ`: เก็บ `SNK.qCh = ch.id`, `SNK.qText = q.q`
- `Snake.answer`: `try{ if(SNK.qCh) SRS.record(SNK.qCh, SNK.qText, correct); }catch(e){}`

ผล: เล่นเกม 2 ตัวนี้ ตอบผิด → ข้อนั้นเข้าคิวทบทวน · ตอบถูกข้อที่เคยติดคิว → เลื่อนขึ้น (จำได้)
(ใช้ SRS.record เดิมที่ unit-test ผ่านแล้ว · guard ch + try/catch กันพังทุกกรณี)
