# ⚔️ v.3 ด้านที่ 3 (ยกระดับ RPG) — เชื่อมข้อที่ผิดใน RPG เข้า SRS ส่วนกลาง — 2026-06-25

## บริบท
RPG "นักผจญภัยเคมี" มีระบบ review/mastery ของตัวเองอยู่แล้ว (`RS.mastery`, `RS.review`, โหมด "ทบทวนข้อพลาด")
แต่แยกจากระบบทบทวนส่วนกลาง (SRS) ที่สร้างใน v.3 → ข้อที่ผิดใน RPG ไม่โผล่ในการ์ดทบทวนหน้าโปรไฟล์

## สิ่งที่ทำ
เชื่อม RPG → SRS ส่วนกลาง ที่ตัวจัดการตอบ `RPG.answer(i)` (จุดเดียว):
```
const ch=RB.qch||CHAPTERS[RB.zi].id; RPG._recordAnswer(ch, i===q.a);
try{ SRS.record(ch, q.q, i===q.a); }catch(e){}   // ← เพิ่ม
```
- โจทย์ RPG ทุกโหมด (ปกติ/ดินแดนลับ/adaptive/ทบทวน) มาจาก `QUIZ_BANK` ทั้งหมด → q.q จับคู่กลับเพื่อทบทวนได้
- RPG เป็น single-player ล้วน → ไม่ต้อง guard บอท
- ระบบ review ภายในของ RPG ยังทำงานเหมือนเดิม (ไม่แตะ) — แค่ "ป้อนเพิ่ม" เข้า SRS ส่วนกลางด้วย

## ผลรวม: วงจรการเรียนรู้ครบทั้งระบบ
ตอนนี้ **ทุกจุดที่ตอบคำถามป้อนเข้า SRS ส่วนกลาง (4 จุด):**
1. แบบทดสอบ (`PK.answer`) — ควิซรายบท + ควิซจากแล็บ + โหมดทบทวน
2. เคมีมาร์เบิล (`Game.answer`)
3. บันไดงู (`Snake.answer`)
4. RPG (`RPG.answer`)
→ ตอบผิดที่ไหนก็ไหลเข้าการ์ด "ทบทวนข้อที่เคยผิด" ในโปรไฟล์ที่เดียว
