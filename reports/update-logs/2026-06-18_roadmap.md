## Phase 1 — ⚡ ประสิทธิภาพ/โหลดเร็ว *(ฐาน ทำก่อน)*
เป้า: ลดเวลา parse/โหลดแรกบนมือถือ (นักเรียนส่วนใหญ่ใช้มือถือ)

1. ✅ **วัด baseline** (เสร็จแล้ว — ตารางด้านบน)
2. **Lazy-load richHTML 14 บท** — แนวทางที่ทำงานออฟไลน์ (file://) ได้:
   ย้าย richHTML แต่ละบทจาก template literal ใน JS ไปเก็บเป็น
   `<script type="text/template" id="chap-c1b1">…</script>` (เบราว์เซอร์ไม่ parse เป็น JS)
   แล้ว `showChapter()` อ่าน `.textContent` ของบทที่เปิดเท่านั้น
   → ตัด parse cost ~1.1 MB ออกจาก startup โดยไฟล์ยังเปิดดับเบิลคลิกได้
3. **Defer QUIZ_BANK / เกม** — ขยาย quiz bank + init เกม แบบ on-demand เมื่อเข้าหน้านั้นจริง
4. **ปรับ Service Worker** — precache เฉพาะ shell, bump version
5. **กันงานพัง** — คง script-scope split เดิม (อย่าย้าย var ข้าม block), guard ทุกจุด,
   ทดสอบ jsc ทั้ง 4 บล็อก, backup ทุกขั้น
   - ความเสี่ยง: ปานกลาง (แตะ render path) → ทำทีละขั้น

## Phase 2 — 📚 เติม/สมดุลเนื้อหาบทเรียน
1. ตรวจครบ 14 บท: ตารางนับ content-section/problem-card/formula-box/h3-h4 ต่อบท
   (ยังไม่ได้เช็ก c5b13, c6b14 — c5b12 เพิ่งเติม IUPAC/isomerism แล้ว)
2. เติมบทบางสุดก่อน ให้ครบมาตรฐาน: จุดประสงค์ → คำอธิบาย → ตัวอย่าง → แบบฝึก →
   เฉลยละเอียด → จุดที่มักผิด → กล่องสรุป
3. ตรวจความถูกต้องเคมีด้วย pkchemistry-review-agent

## Phase 3 — 🖼️ คลังสื่อ + เครื่องมือ
1. คลังสื่อ: ขยายจาก 14 รายการ, จัดหมวดตามบท, filter/ค้นหา (แก้ที่ `data/media.json` + `media-data`)
2. เครื่องมือใหม่: stoichiometry, เจือจางสารละลาย (C₁V₁=C₂V₂), แปลงหน่วยความเข้มข้น, กราฟ titration

## Phase 4 — 📈 การเรียนรู้/ติดตามผล
1. แดชบอร์ดความก้าวหน้าในหน้าโปรไฟล์ (บทที่อ่าน/ควิซ/คะแนน/ความแม่นยำรายบท)
2. ระบบทบทวน spaced repetition (ต่อยอด flashcards — ดึงข้อที่เคยผิดมาทบทวน)
3. รายงานครูผ่าน Firebase teacher sync ที่มีอยู่
