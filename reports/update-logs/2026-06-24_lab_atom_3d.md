# 2026-06-24 · อะตอม 3D (โบร์ 3 มิติ หมุนได้)

ยกแล็บโครงสร้างอะตอม (c1b2) เป็น 3 มิติ ต่อจาก VSEPR 3D

## สิ่งที่ทำ
- เพิ่ม helper 3D ใช้ซ้ำ: `Lab._rot3(p,ay,ax)` (หมุน Y แล้วเอียง X) + `Lab._proj3(v,cx,cy,scale,focal)` (perspective)
- engine `Lab._atomStart(shells,z,nn)`: canvas 3D
  - แต่ละชั้นอิเล็กตรอน = วงโคจรเอียงใน 3 มิติ (tilt ต่างกันต่อชั้น) หมุนอัตโนมัติ ชั้นในเร็วกว่า
  - อิเล็กตรอน z-sorted (ใกล้ใหญ่/ไกลเล็ก) · วงโคจรจาง · นิวเคลียส (Z p⁺ / N n)
- แทน `Lab._bohr` (SVG 2D) → เลิกใช้

## ทดสอบ (jsc + stub)
- _rot3 รักษาความยาวเวกเตอร์ (เป็นการหมุนจริง) ✓ · _proj3 finite ✓
- engine รัน 1–4 ชั้น หมุนได้ทุกแบบ ✓ · guard canvasหาย→หยุด ✓ · HTTP 200

## สถานะ 3D
- เสร็จ: VSEPR 3D, อะตอม 3D
- ถัดไป: เคมีอินทรีย์ (โมเลกุลไฮโดรคาร์บอน 3 มิติ — คาร์บอนเตตระฮีดรัล)
