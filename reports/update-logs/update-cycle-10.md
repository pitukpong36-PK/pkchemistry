## 2. 🎯 ข้อสอบรวมทุกบท (Exam Mode)

- บันทึกคะแนนดีสุดแยกต่างหาก (`quizzes.__exam`) แสดงแถวพิเศษในโปรไฟล์
- แต้มโบนัสจากข้อสอบรวม = คะแนน × 3 (แยกจากคะแนนรายบท)
- **กันข้อมูลปน:** exam ไม่ถูกนับเป็น "บท" ในสถิติ gamification และแดชบอร์ดครู
- ปุ่ม "ทำใหม่" บนหน้าผลลัพธ์เริ่มข้อสอบรวมใหม่ (สุ่มชุดใหม่)

## 3. 📱 PWA — ติดตั้งเป็นแอป + ออฟไลน์
- `<head>` เพิ่ม manifest, theme-color, apple-touch-icon, icon
- Service Worker แคชแบบ cache-first สำหรับไฟล์ same-origin (Firebase/fonts ผ่านเน็ตปกติ)
- ลงทะเบียน SW **เฉพาะเมื่อเปิดผ่าน http/https** (เปิดจากไฟล์ file:// จะข้ามไปอย่างปลอดภัย)
- เมื่อโฮสต์ออนไลน์: ติดตั้งลงหน้าจอหลักได้ + เปิดซ้ำใช้งานออฟไลน์ได้

## หมายเหตุการใช้ PWA
- ต้องโฮสต์บน **https** (เช่น Firebase Hosting, GitHub Pages, Netlify) จึงจะติดตั้ง/ออฟไลน์ได้
- เปิดด้วยดับเบิลคลิก (file://) ทุกอย่างยังทำงานปกติ ยกเว้นฟีเจอร์ออฟไลน์ของ PWA (ข้ามให้อัตโนมัติ)
- เมื่ออัปเดตเนื้อหา ควรเปลี่ยน `CACHE = 'pkchem-v1'` ใน `sw.js` เป็นเวอร์ชันใหม่ เพื่อให้ผู้ใช้ได้ไฟล์ล่าสุด
